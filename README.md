# Pathfinding Visualizer

An interactive Python application that visualizes graph pathfinding algorithms.

## Algorithms

- BFS
- DFS
- Dijkstra
- A* Search

## Features

- Interactive grid
- Wall/obstacle creation
- Draggable start and end nodes
- Random maze generation
- Animated pathfinding
- Path length statistics
- Visited node statistics
- Search time measurement

## Technologies

- Python
- Tkinter
- Data Structures & Algorithms
- Graph Algorithms

## How to Run

python pathfinding_visualizer.py
